Formistory testbed

Every form shape worth testing against, offline. Load the extension, fill one in, then open the popup. Each page states what should be captured so a wrong result is obvious.

  1. Classic HTML form Every native input type, label[for], fieldset/legend, select, multi-select.
  2. SPA with no <form> No form element, no navigation, no submit event — the Ashby shape.
  3. ARIA widgets Choices as div[role=radio]/[role=checkbox] — the Google Forms shape.
  4. Shadow DOM Open roots (must capture) and a closed root (must not — a hard limit).
  5. Multi-step wizard Paged modal with Next/Back/Submit — the LinkedIn Easy Apply and Workday shape. Must produce one document, not one per step.
  6. Iframes Same-origin nested form plus srcdoc.
  7. Sensitive data Passwords, cards, SSN, EEO self-identification. Tests exclusion and redaction.
  8. Dynamic fields Fields injected late, conditional reveals, a repeater that adds rows.
  9. Custom widgets Comboboxes, a fake react-select, contenteditable rich text, range, date, file.
  10. Hostile markup No ids, no names, no labels, generic placeholders, inline <style> between fields.
  11. Rejected submissions Press Submit repeatedly with errors. Must produce one record, not one per press — and rejected attempts stay draft.
  12. Media / social noise Volume, likes, toggles, search, settings. The player must produce zero records; the real form beside it must still be captured.

Automated assertions for these pages live in testbed/testbed.test.js — npm test runs them. Serve this folder with node spike/serve.js.
