06 — Iframes

Expect: 1 field in the top document, plus fields inside each frame captured by the content script running in that frame (all_frames: true). Each frame is its own document, so each produces its own draft — the top frame cannot reach into them. A genuinely cross-origin frame would need host permission for that origin; there is no way to test that offline, so it is listed as a known gap rather than mocked.
